# Verification plan

Run integration, browser, database and inbox cases only on an isolated project with synthetic accounts and dedicated keys. Use configuration snapshots, fixture clocks, received mail metadata and test output. Record test ID, UTC and PHT time, commit, policy configuration, outcome and redacted evidence. Avoid collecting any raw password, answer, code, access token or personal details. The [demo checklist](05-demo-and-submission-checklist.md) records all 20 Section 18 cases. Matrix sections below connect functional tests and every Section 12 protection.
