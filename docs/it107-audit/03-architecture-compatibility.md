# Architecture compatibility

The React/Vite SPA uses React Router with public, Auth, personal workspace, organization and platform-admin routes. The Node/Express API serves authenticated user, organization, notification and admin areas. Supabase Auth owns accounts and JWTs, PostgreSQL stores profiles, organization roles, financial workflows and telemetry, and Storage handles protected evidence. Browser API requests attach explicit bearer credentials. The browser SDK uses PKCE, persistent sessions and refresh. The server validates tokens and calls a database session check. PostgREST and authenticated Storage have their own enforcement points. Keep the identity UUID as the join key for existing data. ## Proposal candidates

Use these as discussion items for a synthetic finance-workspace membership request. Existing roster import has an organization-scoped student identifier and customizable attributes. Finance has reference and payment concepts. No candidate implies eligibility or grants workspace access. Membership remains invitation/approval-driven.

| Candidate | Kind | Proposed requiredness and rule | Example error |
|---|---|---|---|
| Organization enrollment number | Formatted text | Required for student organizations. Use organization-approved format and canonical matching, preserve leading zeroes | Enter the enrollment number in the format provided by your organization. |
| Membership category | Dropdown | Required. Only published organization categories available to applicant. Never accept platform or organization role names as privileges | Select a valid membership category. |
| Membership start date | Date | Optional for existing member reconciliation. Valid dates with permitted academic term scope | Enter a membership start date within the selected term. |
| Prior dues reference | Free text | Optional only if matching prior dues is in the approved workflow. 3–40 approved reference characters; no payment credentials. Candidate for reversible encryption where the owner needs to review the original | Enter a dues reference using 3 to 40 approved characters. |

If the fourth field lacks a legitimate registration purpose, request a substitute before implementation. Keep raw addresses, birthdates, school identifiers and question answers synthetic pending necessity and instructor review. Auth password, answers and OTPs are verifier material and have no need for reversible storage.
